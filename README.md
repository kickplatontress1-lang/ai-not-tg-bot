# 🚀 Telegram бот Детектор нейрослопа

Пример Telegram бота, написанного на Python для распознования нейро картинок и насколько процентов это ИИ или нет

## Установка библиотек

> [!WARNING]
> Для стабильности рекомендуется Python 3.11

```
pip install pyTelegramBotAPI
pip install numpy
pip install keras
pip install requests
pip install tensorflow
pip install Pillow
```

## Получение токена Telegram бота

Чтобы получить токен бота, сначала нужно создать твоего бота через бота BotFather, назвать этого бота и скопировать токен. Вставить токен можно в файле **main.py**
